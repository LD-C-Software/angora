# Security Policy

## Reporting a Vulnerability

Please **do not** open a public issue for security vulnerabilities.

Preferred: use GitHub's [private vulnerability reporting](https://github.com/angoracloud/angora/security/advisories/new) ("Report a vulnerability" under the Security tab). This opens a private draft advisory visible only to maintainers until a fix is ready.

Alternative: email bartu@angora.cloud or burak@angora.cloud with details and, if possible, steps to reproduce.

We'll acknowledge reports as soon as we can and keep you updated as we investigate and fix the issue.
